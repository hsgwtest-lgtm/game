================================================================
## DeepRacerとは何か（体験設計の根拠）
================================================================

DeepRacerはユーザーが「報酬関数」を設計し、その価値観に従って
強化学習エージェント（車）が自律的に学習するML教育サービス。

### ユーザーが体験すべき感動の順序：

1. 「車がめちゃくちゃ走ってる（コースアウトしまくり）」← 学習前の混乱
2. 「世代が進むにつれ、なんとなく走れてきた」← 学習の進行を視覚で実感
3. 「NN可視化パネルで、コーナーで特定ニューロンが光る！」← 内部状態の理解
4. 「スライダーでスピード重視に変えたらコーナーで飛び出した笑」← 因果の体感
5. 「この太い青い線がコーナー検知の回路だ」← AIが何を学んだか見える

本家DeepRacerにはない、**学習過程の透明な可視化**がこのPWAの価値。

### 2. 車（Agent）クラス

```javascript
class Agent {
  constructor(genome) {
    this.x = WAYPOINTS[0].x;
    this.y = WAYPOINTS[0].y;
    this.heading = 0;      // ラジアン
    this.speed = 0;
    this.genome = genome;  // NNの全重みをフラット配列で持つ
    this.nn = new NeuralNet(genome);
    this.alive = true;
    this.fitness = 0;
    this.steps = 0;
    this.distanceTraveled = 0;
    this.closestWaypointIdx = 0;
    this.lapProgress = 0;  // 0〜1
  }

  // センサー（レイキャスト）5本
  // 角度オフセット: [-60, -30, 0, +30, +60] 度
  // 戻り値: [0.0〜1.0] × 5（壁まで遠いほど1.0に近い）
  getSensorReadings() { ... }

  // NNの推論 → ステアリング・スロットルを適用
  update() {
    const sensors = this.getSensorReadings();
    const [steer, throttle] = this.nn.forward(sensors);
    this.heading += steer * 0.08;
    this.speed = throttle * 3.0; // max 3.0 px/frame
    this.x += Math.cos(this.heading) * this.speed;
    this.y += Math.sin(this.heading) * this.speed;
    this.steps++;
    // コース逸脱チェック → this.alive = false
    // 進捗更新 → this.lapProgress更新
    // フィットネス更新
    this.updateFitness();
  }

  updateFitness() {
    // ユーザーのスライダーウェイトを使った報酬計算
    // reward = Σ(各項目スコア × weight)
    const distFromCenter = this.getDistFromCenter(); // 0〜TRACK_WIDTH/2
    const centerScore = 1.0 - (distFromCenter / (TRACK_WIDTH / 2));
    const speedScore = this.speed / 3.0;
    const steerScore = 1.0 - Math.abs(this.lastSteer);
    
    this.fitness += (
      centerScore * rewardWeights.center +
      speedScore  * rewardWeights.speed +
      steerScore  * rewardWeights.zigzag
    );
  }
}
```

車の描画：
- 小さな三角形（向きあり）
- 通常個体: rgba(100,160,255,0.7)（薄い青）
- ベスト個体（前世代1位）: #00d4ff + グロー効果
- レイキャスト5本: ベスト個体のみ表示
  - 壁まで届いた点: 小さな丸
  - 線色: rgba(0,212,255,0.3)

### 3. ニューラルネット

```javascript
class NeuralNet {
  // 構造: 5 → 6 → 2
  // 活性化: Hidden=tanh, Output=[tanh(steer), sigmoid(throttle)]
  // 重み数: 5×6 + 6×2 = 42個 → genome配列

  constructor(genome) {
    // genome[0..29] = W1(5×6), genome[30..41] = W2(6×2)
  }

  forward(inputs) {
    // hidden: tanh(W1 × inputs)
    // output: [tanh(W2[0] × hidden), sigmoid(W2[1] × hidden)]
    // 戻り値: [steering -1〜+1, throttle 0〜1]
    
    // ★ 可視化用に活性化値を保存する
    this.inputActivations = inputs;
    this.hiddenActivations = hidden; // 6個
    this.outputActivations = output; // 2個
    this.weights1 = W1; // 5×6
    this.weights2 = W2; // 6×2
    
    return output;
  }
}
```

SIMPLEモードの報酬計算（Agent.updateFitness内で毎ステップ実行）：

```javascript
function computeReward_simple(agent) {
  const w = rewardWeights; // 各スライダー値（0〜1に正規化済み）

  // 軸1: センター維持（0〜1、センターほど1.0）
  const distRatio = agent.distFromCenter / (TRACK_WIDTH / 2);
  const centerScore = Math.max(0, 1.0 - distRatio);

  // 軸2: スピード（0〜1、最大速度で1.0）
  const speedScore = agent.speed / MAX_SPEED;

  // 軸3: ステアリング安定（急ハンドルをペナルティ）
  const smoothScore = 1.0 - Math.min(1.0, Math.abs(agent.lastSteer) / 1.0);

  // 軸4: 進捗（lapProgressが増加したら加点）
  const progressScore = agent.lapProgress; // 0〜1

  // 軸5: ウェイポイント方向整合
  // 次のウェイポイントへの方向と現在headingの差分（小さいほど高報酬）
  const waypointDir = agent.getWaypointHeading(); // ラジアン
  const headingDiff = Math.abs(normalizeAngle(agent.heading - waypointDir));
  const headingScore = 1.0 - Math.min(1.0, headingDiff / Math.PI);

  // 軸6: 生存ボーナス（生きているだけで小さな報酬）
  const surviveScore = 1.0; // alive中は常に1.0

  return (
    centerScore   * w.center   +
    speedScore    * w.speed    +
    smoothScore   * w.smooth   +
    progressScore * w.progress +
    headingScore  * w.heading  +
    surviveScore  * w.survive
  );
}
```

CUSTOMモードの実装仕様：

```javascript
// テキストエリアの内容をevalして関数を取得
let customRewardFn = null;

function applyCustomReward() {
  const code = document.getElementById('custom-editor').value;
  try {
    // セキュリティ: new Function でサンドボックス的に評価
    // （PWA内完結のため、evalで問題なし）
    customRewardFn = new Function('params', 
      code.replace(/^function reward\(params\)\s*\{/, '')
          .replace(/\}$/, '')
    );
    setEditorStatus('✅ VALID', 'cyan');
  } catch(e) {
    customRewardFn = null;
    setEditorStatus(`❌ ERROR: ${e.message}`, 'red');
  }
}

function computeReward_custom(agent) {
  if (!customRewardFn) return 0;
  try {
    const params = {
      distFromCenter:    agent.distFromCenter,
      trackWidth:        TRACK_WIDTH,
      speed:             agent.speed,
      steerAngle:        agent.lastSteer,      // -1〜+1
      progress:          agent.lapProgress,
      headingError:      agent.headingError,   // 0〜π
      steps:             agent.steps,
      lapProgress:       agent.lapProgress,
      allWheelsOnTrack:  agent.alive,
      isReversed:        agent.isReversed,
      x: agent.x, y: agent.y,
      closestWaypointIdx: agent.closestWaypointIdx,
    };
    const r = customRewardFn(params);
    // NaN/Infinity/負の値をガード
    return (typeof r === 'number' && isFinite(r)) ? Math.max(0, r) : 0;
  } catch(e) {
    return 0;
  }
}
```

```javascript
// 速く走るほど高報酬。センターを外れたらペナルティ
function reward(params) {
  const { speed, distFromCenter, trackWidth, allWheelsOnTrack } = params;
  if (!allWheelsOnTrack) return 0;
  const speedReward = speed / 3.0;
  const centerPenalty = distFromCenter > 0.4 * trackWidth ? 0.3 : 1.0;
  return speedReward * centerPenalty;
}`,

  '進捗マイルストーン': `
// 一定ステップ数ごとに進捗が期待値を超えたらボーナス
function reward(params) {
  const { steps, lapProgress, allWheelsOnTrack } = params;
  if (!allWheelsOnTrack) return 0;
  let reward = lapProgress;
  if (steps % 100 === 0 && lapProgress > steps / 800) {
    reward += 5.0; // マイルストーンボーナス
  }
  return reward;
}`,

  'ジグザグ防止': `
// ステアリングが穏やかなほど高報酬
function reward(params) {
  const { steerAngle, allWheelsOnTrack, speed } = params;
  if (!allWheelsOnTrack) return 0;
  const steerPenalty = Math.abs(steerAngle) > 0.5 ? 0.5 : 1.0;
  return speed / 3.0 * steerPenalty;
}`,

  'ウェイポイント方向': `
// コースの進行方向と車のheadingが合っているほど高報酬
function reward(params) {
  const { headingError, allWheelsOnTrack, distFromCenter, trackWidth } = params;
  if (!allWheelsOnTrack) return 0;
  const dirScore = 1.0 - Math.min(1.0, headingError / Math.PI);
  const centerScore = 1.0 - distFromCenter / (trackWidth * 0.5);
  return dirScore * 0.6 + centerScore * 0.4;
}`,
};
```

プリセット選択時、エディタ内容をそのまま置換（確認ダイアログ小表示）。
