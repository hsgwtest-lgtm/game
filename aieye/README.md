# AI EYE 64 — 64×64の目で走る教習所

あなたの運転をお手本に、64×64ピクセルのカメラ画像だけを見るAIが運転を覚える、模倣学習のPWAです。

https://hsgwtest-lgtm.github.io/game/aieye/

## 遊び方

1. **教える** — ◀ ▶ でコースを2〜3周走る。AIの目（64×64の画像）と操作（左・直進・右）がセットで記録される
2. **学習** — 小さなCNNが端末の中で学習する。学習中もAIが走るので、回ごとの上達が見える
3. **AIが運転** — 学習したAIが運転する。AIの目の上のヒートマップ（Grad-CAM）が、判断の手がかりにした場所を示す。危ない場面で ◀ ▶ を押すと、その場面を記録に足して教え直せる

## しくみ

- 3D表示は Three.js（`lib/three.module.min.js` に r186 を同梱。オフラインでも動く）
- AIの目は車載カメラを 128×128 で描画し、2×2 平均で 64×64 に縮めたもの。1秒に10回撮って判断する
- CNN は外部ライブラリなしの素の JavaScript（`js/cnn.js`）。誤差逆伝播・Adam・Grad-CAM まで実装
  - 入力 3×64×64 → 畳み込み 8×30×30 → 16×14×14（Grad-CAM はここ）→ 24×6×6 → 全結合 32 → 3
  - 学習は Web Worker（`js/trainer.js`）で行い、画面の描画を止めない
  - 7枚に1枚は学習に使わない検証データ。左右反転（左と右のラベルを入れ替え）で水増し
- 記録した場面は IndexedDB、学習済みの重みは localStorage に保存（開き直しても続きから）
- 「ずらした目でも記録」をオンにすると、左右に10°向けた画像に「戻す操作」をつけて記録する

## ファイル

| ファイル | 役割 |
|---|---|
| `js/main.js` | 画面・3Dコース・運転・記録・学習の呼び出し |
| `js/track.js` | コースの形、車の動き、お手本ドライバー（テスト用） |
| `js/cnn.js` | CNN（順伝播・逆伝播・Adam・Grad-CAM・学習ループ） |
| `js/trainer.js` | 学習用 Web Worker |
| `js/datastore.js` | 記録の保存（IndexedDB） |
| `tools/make_icons.py` | アイコン生成（`python3 tools/make_icons.py`） |

URL に `?expert=1` を付けると、教えるモードでお手本ドライバーが自動で運転します（動作確認用）。
