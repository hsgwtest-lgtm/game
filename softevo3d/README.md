# SoftEvo 3D — ボクセル生物 しんかラボ

ブロック（ボクセル＝3Dのドット）で組んだ自分だけの生き物が、ニューラルネットワークの脳を進化させて、
**世代をかさねて すこしずつ 歩きかたを おぼえていく** のを見守る、全画面ドット絵の進化シミュレーターです。
softevo8 の「自分が作った生物の進化を観察する」体験を参考に、3D・ドット絵・スマホ前提でゼロから設計しました。
ビルド不要・外部依存なし（Three.js r128 を同梱）、iPhone の PWA としてオフラインでも遊べます。

## 何が面白いのか・ユーザーは何を求めているのか

設計に入る前に、まずここを決めました。

| ユーザーが本当に欲しいもの | SoftEvo 3D での答え |
|---|---|
| **自分の作品が「生きている」実感** | 体は自分で組む。前の面には目がつき、名前をつけ、レベルと称号が育つ。図鑑に並んで愛着がわく |
| **成長の過程をじっくり楽しみたい**（突然の瞬間より、少しずつの変化） | 標準は **ゆっくり成長**: 1世代ずつ、その世代の王者の10秒の走りを最後まで見せる。前の王者（白）と、王者に挑んだ新入り（金）がゴーストで並び、「どこが少し良くなったか」が見える。世代の終わりに **けっかカード**（何cm のびたか・群れ全員の成績） |
| **待ってもいいが、急いで育てたい時もある** | **急成長** モードに切り替えると、裏で休まず進化（ワーカーを全部使う）。できごとはお知らせで流れる。いつでもゆっくりに戻せる |
| **成長を「数字以外」で実感したい** | 記録の旗をこえた瞬間に「きろく こうしん！」。**レベル**（生まれたときからの のび で上がる。序盤は小刻み）と称号（もぞもぞ→よちよち→てくてく…）。**成長パレード**で第0世代から今までの自分を同時に走らせる |
| **予想外の発見を楽しみたい** | 進化が見つけた動き方を自動で見分けて「**わざ**を おぼえた！」として集める（てくてく・ぱかぱか・ぴょんぴょん・ころころ・さかさあるき…） |
| **昔の自分を見返したい** | 毎世代の王者を全部記録。成長グラフをなぞって好きな世代を選び、**アルバム**として再生（今の自分がゴーストで並ぶ） |
| **なぜ動くのか知りたい** | **同じ色の筋肉は同じ神経で動く**（色＝脳の配線）。脳の画面では出力ニューロンが体と同じ色で光り、前の王者から変わったつながりがピンクで見える。**しゅじゅつ**でニューロンを止めると、走っている最中の動きが変わる。**リズム**の画面は足の接地と筋肉の動きを楽譜のように表示 |
| **作る→試す→直すをくり返したい** | 面をタップして積むだけ（Minecraft のように）。ミラーで左右対称。「ためす」ででたらめな脳のまま動かして確認。育てた後でも **かいぞう** でき、脳は名前の同じ入出力どうしで引きつがれる |
| **見せびらかしたい** | **共有コード**（URL）で体と脳を送れる。物理が決定論的なので、相手の端末でもまったく同じ動きになる。図鑑の生き物どうしで **かけっこ大会** も |
| **レトロゲームの雰囲気** | 3D を低解像度に描き、深度から輪郭線 → ベイヤーディザ → 32色（Endesga 32）に減色。文字・ボタン・グラフもすべてドットで描画。効果音とBGMはその場で合成するチップチューン |

## あそびかた

1. **ずかん** で「＋つくる」→ からっぽ or おてほん（イヌ・トカゲ・カニ・カエル・イモムシ・ヘビ・スライム）を選ぶ
2. **からだを つくる**: 素材を選んで面をタップ。ドラッグで回転、2本指でズーム
   - ほね（かたい・おもい）/ やわらか（ぷにぷに・すべりにくい）/ ツルツル（よくすべる）/ 筋肉A〜F（6色）
   - 筋肉は脳の信号で ふくらむ・ちぢむ。**同じ色の筋肉は同じ出力ニューロン**につながる
   - ミラーON だと、反対側には となりの色（A↔B, C↔D, E↔F）が置かれ、左右を別々に動かせる
3. **そだてる** → 名前をつけると、30匹のきょうだいが卵から生まれる
4. **しんかラボ**: いちばん遠くまで進めた子たちが親になり、次の世代が生まれる
   - 下のボタン: ゆっくり／急成長・再生速度（x1/x2/x4）・スキップ・進化の一時停止・カメラ・メニュー
   - タブ: せいせき（成長グラフ→タップで昔の世代へ）・のう・リズム・にっき（ぼうけんのしょ）
   - メニュー: つよさ・かんきょう（地形・重力・目的）・成長パレード・なかまのゴースト・かいぞう・共有コード

## しくみ（技術メモ）

### 体: ボクセルのやわらかい格子
- ボクセル1個 = 8つの角（節点）を **28本の距離拘束**（12辺＋12面対角線＋4体対角線）でつないだ立方体
- となりのボクセルとは角と辺を共有し、共有された拘束は周りのボクセルのかたさを足し合わせる（有限要素法の組み立てと同じ考え）
- 筋肉のボクセルは脳の信号で自然長が ±30% 変わる（体積ごとふくらむ・ちぢむ）。共有された拘束の自然長は、周りのボクセルのかたさで重みづけした平均
- 角だけ・辺だけでつながったボクセルは、自然に「関節」になる

### 物理: XPBD スモールステップ法（決定論的）
- 1フレーム(1/60秒)を6回に分け、各回で 重力 → 拘束 → 地面 を1回ずつ解く
- 拘束の補正は2点を結ぶ線の向きにだけかかるので、運動量も角運動量も生まれない（数値の永久機関で飛んでいくズルが進化しない）。減衰も同じ向きだけ
- 地面の摩擦は、めりこみ深さに比例した分だけ横ずれを止める（クーロン摩擦）
- 筋肉は一瞬では動けない（反応時間0.1秒のローパス）。振動を悪用したズルを防ぎ、動きも生き物らしくなる
- **決定論**: `Math.sin` などは端末ごとに最後の1ビットが違いうるので、sin・exp・tanh は四則演算と sqrt だけで自作（`js/sim/dmath.js`）。重みは float32 で表せる値に丸めてあり、保存しても再生がずれない。ワーカーで評価した個体を画面で寸分違わず再生でき、共有コードを開いた相手の端末でも同じ動きになる

### 脳
| 入力 | 内容 |
|---|---|
| 筋肉ののび | 色ごとに、筋肉ボクセルの体対角線の長さ（固有感覚） |
| 足のせっち | 体を前後×左右の4区画に分け、地面に触れている角の数 |
| 体のかたむき | 重力の向きを体の座標で（3） |
| 速さ | 重心の速度を体の座標で（3） |
| ゴールの向き | 進む方向（+X）を体の座標で（2）。まっすぐ進むのに使える |
| リズム | 脳内の振り子 sin, cos。周期は遺伝子で進化する |

出力は筋肉の色ごとに1つ（tanh）。隠れ層1層（8/12/16、標準12）。体全体の向きは Müller ほか(2016)の反復法で、前フレームの値から数回の反復で推定。

### 進化
- 30匹（20/30/40）、エリート保存（上位10%）、トーナメント選択、ニューロン単位の交叉、ガウス突然変異
- 伸びなやむと突然変異を自動で強める（「のびなやみ…」）
- 1世代ごとに王者を記録（成長アルバム）。レベル・わざ・記録の判定は `js/evo/session.js` / `js/evo/growth.js`
- 評価はワーカー（`js/evo/worker.js`）で。使えない環境ではメインスレッドで少しずつ

### 全画面ドット化（BIT BIRDS / DOT DOJO と同じエンジン）
1. Three.js r128 で 3D を **低解像度レンダーターゲット**（iPhone 12 で幅195ピクセル）に描画
2. ポストエフェクトで **深度から輪郭線** → **4×4 ベイヤーディザ** → **Endesga 32 パレットに減色**
3. UI は自前のフレームバッファ（`js/gfx/fb.js`）に1ピクセルずつ描画（文字は PixelMplus10 のビットマップ）
4. ゴーストは半透明のかわりに市松模様に穴をあけて描く
5. ノッチ対応: `env(safe-area-inset-*)` を仮想ピクセルに換算。`?safe=47,34` で iPhone 12 のノッチを再現

### 保存
- IndexedDB（生き物の記録・群れ・成長の記録 / 世代ごとの王者）。JSON ファイルへの書き出し・読み込み
- 共有コード: 体＋いちばん良い脳を deflate 圧縮して URL（`#c=...`）に

## ファイル構成

```
softevo3d/
  index.html  style.css  manifest.json  sw.js  icons/  lib/three.min.js（r128 同梱）
  js/main.js                ループ・画面遷移・共通サービス
  js/sim/                   物理と脳（DOM なし・ワーカーと共有）
    body.js                 設計図 → 節点・拘束・面
    creature.js             物理（XPBD）・感覚・脳・成績
    brain.js  dmath.js      ニューラルネット・決定論的な数学
    terrain.js  presets.js  地形・おてほん
  js/evo/                   進化
    ga.js  pool.js  worker.js  session.js  growth.js
  js/world/                 3D（空・地形・旗・カメラ / ボクセルのメッシュ / 設計画面）
  js/gfx/                   ピクセル描画・フレームバッファ・ドット文字・アイコン
  js/ui/                    入力・UI部品・重ねる窓・見える化・等角図
  js/screens/               タイトル・ずかん・からだ・しんかラボ・パレード・せってい
  js/core/                  定数・乱数・音・保存・共有
  tools/                    開発用スクリプト
```

## 開発用スクリプト

```bash
node tools/sim_test.mjs          # 物理の確認（静止・暴れても壊れない・決定論）
node tools/evo_test.mjs inu 40   # ブラウザなしで学習できるか（おてほんのkey, 世代数）
node tools/session_test.mjs      # 育成セッション（できごと・保存→読みこみ後も同じ続きになるか）
node tools/ga_sweep.mjs '{"sigma":0.4}' inu,tokage 30 1,2,3   # GAの設定くらべ（記録の伸びと、伸びた世代の数）
node tools/make_demo.mjs 70      # タイトル画面で歩く脳を作り直す
node tools/check_imports.mjs     # モジュールの import/export チェック
python3 tools/build_font.py      # 文章を変えたらドット文字アトラスを作り直す
python3 tools/build_sw.py        # ファイルを変えたら Service Worker のキャッシュ一覧を更新
python3 tools/make_icons.py      # アイコン生成
```
