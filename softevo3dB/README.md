# SoftEvo 3D B — 骨と筋肉の進化記

骨を組み、関節を決め、筋肉をつける。動かし方は教えない。
あなたが設計した体に、**神経が進化して動き方を見つけていく**3D進化シミュレーションです。
変わりゆく惑星で、あなたの種は地方の「ぬし」を破って定着し、枝分かれして広がり、ときに絶滅します。

ビルド不要・PWA（iPhone 12 で動くことを目標）。Three.js r128 のほかは外部依存なし。

## 何を大事にしたか

前作（ピクセルの softevo3d）は「設計して進化させるだけの場」になっていた。
今回は「なぜ進化させたくなるのか」から組み立て直した。

| 遊ぶ人がほしいもの | このゲームでの答え |
|---|---|
| **自由に体を作りたい** | 骨は最大40本。関節は4種類（ひじ型・くび型・かた型・こてい）で、軸ごとに曲がる範囲を決められる。太さ・長さ・重さ・形（丸／板）も自由。左右対称モード、元に戻す、見本（サカナ・トカゲ・イヌ・ムシ・カエル・トリ・ヒト）は「ただの出発点」 |
| **本物の体の手ごたえ** | 骨は剛体、筋肉は Hill 型（長さと速さで出せる力が変わる、引くだけで押せない）。関節ごとに曲げる筋肉と伸ばす筋肉の対が自動でつき、2関節筋も足せる |
| **成長をじっくり見たい** | 既定は「ゆっくり」: 1回の再生ごとに1世代。はじめはもがくだけ、やがて立ち、歩き、走る。待てないときは「はやく」 |
| **進化させたくなる理由** | 地方ごとに「ぬし」がいて、その記録を破ると定着できる。ぬしのゴーストがいつも横を走っている。定着すると、となりの地方へ枝分かれできる |
| **物語がほしい** | 定着した地方がふえると時代が進む（氷河期・大乾燥・大海進）。環境が変わった地方の種は危機になり、次の時代までに適応できなければ絶滅する。誕生・分岐・定着・危機・絶滅は年代記と系統樹に残る |
| **道筋は決めないでほしい** | どの地方から始めてもよい。どんな体でもよい。ヒトの形は「作れば作れる」だけで、ゴールではない |
| **体の中で何が起きているか知りたい** | 「筋肉」表示では力を出している筋肉が朱色に光る。神経タブでは関節ごとの指令が見え、神経を切る実験もできる。歩き方タブでは足あと図と歩き方の種類（なみあし・はやあし・ギャロップ・二足歩行…） |
| **ヒトと同じ動きが再現できるか** | 二本足の体なら、股・ひざ・足首の角度を1歩ごとにそろえて、ヒトの平地歩行の代表的な曲線とくらべる（100点満点）。めざす動きを「ヒトの歩き方をまねる」にすると、その曲線に近づく方向へ進化する |
| **だれかと競いたい** | 物理が決定論なので、生き物（設計図＋遺伝子）を送るだけで、だれの端末でも寸分違わず同じ動きになる。地方ごとのランキング、かけっこ、すもう（同じ世界でぶつかり合う） |

## しくみ

### 物理（`js/sim/physics.js`）
- 骨はカプセルか箱の剛体。XPBD（Müller ほか 2020）で、1フレーム（1/60秒）を10回に分けて解く。
- 関節は「つなぎ目の位置」と「3軸の可動域（オイラー角を範囲に収める回転の拘束）」。
- 筋肉は 起始 → 滑車 → 停止 の通り道に沿って骨を引く。力 = 活性度 × 長さの特性 × 速さの特性 ＋ のびすぎたときの弾性。
- 地面との接触はクーロン摩擦。水は浮力と、骨の向きで違う抵抗（横に強く、縦に弱い → くねらせると進む）。
- 四則演算と sqrt と自前の三角関数だけを使うので、**どの端末でも同じ結果**になる（オンライン対戦の前提）。

### 神経（`js/sim/nerves.js`）
どんな体の形でも、同じしくみで動く。
1. **リズム（CPG）**: 関節の軸ごとに、共通の位相 φ のフーリエ級数で目標の角度を作る。左右の相方は半周期ずらす。
2. **平衡感覚**: 胴の傾き・傾く速さ・速さのずれ・重心と支えのずれ・向きのずれを「立て直しに必要な回転」にまとめ、各関節の軸へ射影する。足が地面についているか（立脚／遊脚）で別の重み。
3. **脊髄反射**: 目標とのずれから必要なトルクを求め、その向きに引ける筋肉へ、いまの長さで出せる力の割合で割りふる。筋肉の反応の速さは体の大きさに合わせる（ヒトで25ms、虫で7ms）。
4. **生まれつきの反射**: 遺伝子が0でも、脚は「振り出し」の半周期に足を持ちあげ（足ぶみ反射）、二本足なら胴をまっすぐに保とうとする（立ち直り反射）。進化はここから出発し、強めたり、弱めたり、逆にしたりする。

遺伝子の数は体で決まる（全体7 ＋ 関節の軸のグループごとに10 ＋ 足の組ごとに1）。体の大きさで割った量を使うので、虫でもヒトでも同じ意味になる。

### 進化（`js/evo/`）
- **CMA-ES**: 1世代に十数匹の「きょうだい」を、親の遺伝子のまわりに生む。うまくいった変化の向きと大きさを覚えるので、100を超える遺伝子でも早く上達する。
- 評価は Web Worker で並列に。画面では、その世代のいちばんを**まったく同じ動きで**再生する。
- 成績 = 姿勢を保ったまま進んだ距離 ＋ 倒れずにいた時間 − 使ったエネルギー − 関節を可動域のはしに押しつけた時間（背の高い体ほど、倒れないことの価値が大きい）。
- **支えの手**: 自分では立っていられない体には、はじめ見えない手が胴を支える。倒れずに進めるようになるたびに、少しずつ手を放していく。
- **体を作りかえても**、同じ骨・同じ関節の軸の遺伝子は親から受けつぐ（`inherit.js`）。

### 物語（`js/game/`）
- 7つの地方（うみ・あさせ・そうげん・さきゅう・もり・いわやま・ひょうげん）。地形・水・すべりやすさが違う。
- 地方の「ぬし」は、見本の体をその地方であらかじめ進化させたもの（`tools/make_masters.mjs`）。ぬしの記録は、その時代の環境で毎回計算しなおす。
- 時代: はじまりの時代 → 氷河期（定着2） → 大乾燥（定着4） → 大海進（定着6）。

## オンライン（Firebase）

softevo8 と同じ Realtime Database の `softevo3dB/v1` の下を使います。データベースのルールに、次の1行を加えてください。

```json
"softevo3dB": { ".read": true, ".write": true }
```

- `creatures/{id}` … 公開された種（設計図・遺伝子・公式コースの記録）
- `stats/{id}` … 拍手・すもうの勝ち負け（サーバー側で加算）

だれでも書き込めるので、受け取ったデータはすべて検査してから使います（`checkCreature`）。
記録は公開する人の端末で測りますが、決定論なので見る人の端末で測りなおせます。

## 開発用の道具

```bash
# ブラウザなしで進化させる（例: イヌを100世代、10秒の試しで）
node tools/train.mjs dog 100 '{"T":10}'
# 動きの連続写真（ローカルサーバーが必要）
node tools/sheet.mjs human <genes.json> out.png 3,3.2,3.4 "yaw=0&pitch=0.1"
# ぬしを書き出す（tools/masters/<地方>.json → js/game/masters.js）
node tools/make_masters.mjs
```
