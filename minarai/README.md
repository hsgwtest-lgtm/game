# 見習いアーム — 32×32の目で仕事をおぼえる

32×32ピクセルの「目」しか持たないロボットアーム（関節2つ＋グリッパー）に、仕事を教えるゲームです。
同じ現場を **模倣学習・強化学習・模倣→強化** の3通りで育てて、検定の合格率をくらべられます。学習はすべて端末の中で行います。iPhone の PWA として遊べます。

`https://hsgwtest-lgtm.github.io/game/minarai/`

## あそびかた

1. **教える** — 指で机をなぞると手先がついてくる。ブロックの上で「にぎる」、置き場の上で「はなす」。お手本ロボに頼むこともできる
2. **まねる**（模倣学習）— お手本と同じ行動を選べるように学習する。動きを見ながら指で直すと、その直し方がお手本に加わる（手直し）
3. **練習**（強化学習）— 32台の分身が同時に何万歩も試して、ごほうびが増える動きを覚える。ごほうびの重みは「ごほうび設計」で変えられる
4. **検定** — 決まった100問で合格率を測る。60%で★、85%で★★、97%で★★★
5. **くらべる** — 3通りの育て方の成績を、同じグラフと表で見る

育て方は現場ごとに3通り。それぞれ別の頭脳として育ち、別々に★がつきます。

| 育て方 | 使う手順 | 手間の数え方 |
| --- | --- | --- |
| 模倣学習 | 教える → まねる → 検定 | お手本の本数 |
| 強化学習 | 練習 → 検定 | 練習量（歩数） |
| 模倣→強化 | 教える → まねる → 練習 → 検定 | お手本の本数＋練習量 |

## 長く遊ぶための仕組み

- **8現場 × 3通り × ★3 = ★72**。★の合計で肩書きが上がる（見習い → … → 神の手）
- **最少記録**: ★1・★2・★3 それぞれを、いちばん少ないお手本／練習量で取った記録が残る。少ない本数で合格するには、良いお手本と手直しの腕が要る
- **ごほうび設計**: 近づく・つかむ・運ぶ・成功・時間のばつ の重みを変えて、覚え方の違いを試せる
- **引き継ぎ**: ほかの現場で育てた頭脳を出発点にできる（引き継いだ成績は最少記録には数えない）
- **水増しの入切**: お手本を「机ごと回す・左右を裏返す」で増やす工夫を、切って違いを見られる

## しくみ

- **世界**（`js/core/env.js`）: 机を真上から見た平面。行動は1歩ごとに 肩（−／止／＋）・ひじ（−／止／＋）・グリッパー（開く／にぎる）の3つを同時に選ぶ
- **AIの目**（`js/core/raster.js`）: 64×64 で描いて 2×2 を平均した 32×32 のカラー画像。学習中は何十万枚も描くので、WebGL を使わない自前の描画（1枚 約10µs）
- **頭脳**（`js/core/nn.js` の KeyNet、重み 約2.7万個。外部ライブラリなしの素の JavaScript）
  - 画像 → 畳み込み2層 → チャンネルごとの重心 ＝ **注目点**10個（どこに何があるかを座標で取り出す）
  - 関節センサー（肩・ひじの角度、グリッパーの開閉）→ ひじと手先の位置（注目点2個ぶん）。画像＋関節角は、実機の模倣学習（ACT など）と同じ入力の組み合わせ
  - 注目点どうしの内積・外積（机ごと回しても変わらない量）→ 全結合2層 → 行動の点数8つ
  - 画像のほとんどは黒（0）なので「0 でない所だけ計算する」形にしてある。これで TensorFlow.js などを使わずに、毎秒1,000歩以上の強化学習が回る
- **模倣学習**（`js/core/bc.js`）: ビヘイビア・クローニング。お手本は場面の状態で覚えておき、学習のたびに回転・左右反転して描き直す。お手本ロボは、わざと15%ほど違う動きをして、立て直し方もお手本に入れる
- **強化学習**（`js/core/ppo.js`）: PPO。32台を同時に動かして64歩ずつ集め、2周学習。方策（アクター）は画像と関節センサーだけ、価値の見積もり（クリティック）は位置の数値を直接もらう非対称の組み合わせ。模倣から続けるときは、最初の3周はクリティックだけ育てる
- **裏方**（`js/core/worker.js`）: 世界・AIの目・学習はすべて Web Worker の中。画面の操作と3D表示（Three.js r186 を `lib/` に同梱）は止まらない
- **保存**: お手本と頭脳の重みは IndexedDB、★と記録は localStorage（どちらもこの端末の中だけ）

ブラウザなしで学習を回した実測（`node tools/lab.mjs`、成功率は300〜500回の平均。乱数で毎回少し変わる）:

```
模倣学習だけ（お手本ロボ・40周）     10本    20本    50本    100本
  2.つかむ                          87%     93%     99%    100%
  4.どこでも                        35%     62%     97%    100%
  6.回る台                          46%     69%     97%    100%
  7.仕分け                           –      32%     71%      –

強化学習だけ（お手本なし）
  1.タッチ      6万歩で 100%
  3.はこぶ      25万歩で 約98%
  4.どこでも    25万歩で 88%
  7.仕分け      20万歩で 14% → 45万歩で 約60% → 90万歩で 85%

模倣→強化
  4.どこでも    お手本20本（模倣だけでは 52%）→ 練習20万歩で 99%
  7.仕分け      お手本30本（模倣だけでは 55%）→ 練習25万歩で 92%
```

「仕分け」は、強化学習だけだと立ち上がりまで20万歩かかり、模倣だけでは手順の長さで取りこぼす。合わせ技がいちばん早い現場になっている。

開発用:

- `node tools/lab.mjs expert` … お手本ロボの成功率（全現場）
- `node tools/lab.mjs bc stage=anywhere demos=20,50` … 模倣学習だけの成績
- `node tools/lab.mjs rl stage=touch steps=100000` … 強化学習だけ（`demos=20` を付けると模倣→強化）
- `node tools/check_nn.mjs` … 逆伝播の検算と速さの計測
- `node tools/flow.mjs grasp` … ヘッドレスのブラウザで 教える→まねる→検定→練習 を通し確認
- `python3 tools/build_sw.py` … オフライン用キャッシュ（`sw.js`）の作り直し。ファイルを変えたら実行する
- URL に `?s=place&m=rl&step=practice` を付けると、その現場・育て方・手順を直接開く
