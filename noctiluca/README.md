# NOCTILUCA — 十万の光、ひとつの本能

深海で生まれた **十万の光の粒（夜光虫）** の群れ。リーダーはいません。全員が、まったく同じ小さな脳 ──「本能」を持っているだけ。
十万匹に命令することはできない。だから **本能そのものを機械学習（進化戦略）で探す** ── それがこのゲームです。iPhone の PWA として遊べます。

`https://hsgwtest-lgtm.github.io/game/noctiluca/`

## なぜ機械学習なのか

| ふつうのゲーム | NOCTILUCA |
| --- | --- |
| プレイヤーがキャラクターを動かす | 十万の粒は、それぞれ自分のまわりしか感じられない。一匹ずつ動かすことはできない |
| 動きはプログラマーが決める | 「何を感じたら、どう動き、いつ光るか」というきまり（本能）を、人が書くのはとても難しい |
| — | だから **全員が共有する1つのニューラルネットの重み** を、進化戦略で探す。見つかった本能は、1,024粒で学んでも十万粒でそのまま働く |

## あそびかた

深海 4000m から海面をめざして、5つの試練を進みます。試練ごとに感覚器官がふえ、脳の神経がふえます。

| 試練 | 水深 | めざすこと | 新しい感覚 | 成績 |
| --- | --- | --- | --- | --- |
| 1. 熱水の揺りかご | 4000m | 餌場を見つけて生きのびる | におい（餌） | 生存 |
| 2. 岩の迷路 | 3000m | 上から差す光をたよりに迷路をぬける | 触覚・外の光 | 出口への到達 |
| 3. クラゲの影 | 2000m | 群れを追うクラゲから逃げる（神経 12） | 振動・仲間の気配 | 生存 |
| 4. 光のことば | 1000m | 闇の中で、光で危険を知らせあう | 発光（自分で光り、仲間の光を感じる） | 生存 |
| 5. 月のリズム | 200m | 洞窟に差す月の明滅に、群れ全体で光をそろえる（神経 16） | — | 同調 |

1. **進化させる** … 16 の並列世界に、16 通りの本能を入れて同時に走らせる（1世代 = 10秒）。成績のよかった変異の向きへ本能が動く
2. **本番に挑戦** … いまの最高記録の本能を、**131,072 粒**の群れにそのまま移して試す。★1 以上で次の試練へ
3. 本番では指で遊べる: 餌場を置く（試練1）・光をともす（試練2・5）・クラゲをつかんで動かす（試練3・4）

**ラボ（えらぶ進化）** では、海の条件（餌場・クラゲ・岩・暗い海・海面の光）を選び、気に入った世界をタップして選ぶと、その本能の方向へ進化します（インタラクティブ進化）。

### 学習の過程を見るための画面
- **16 の並列世界**: 左上「いま」= 平均の本能 μ、「最高」= これまでの最高記録、残り 14 = 鏡あわせの変異体 7 組。世代の終わりに 1〜3 位が光る。タップすると拡大
- **学習曲線**: いまの本能と最高記録の成績、★の線
- **本能のくせ**: 感覚ごとに「近づく／離れる」「速く／遅く」「光る／消える」を表で。世代ごとに白い印（前の世代）からバーが動く
- **脳**: 重みの地図（行 = 神経、列 = 入力、右 = 出力。下の段は入力から出力への近道）。青 = プラス、ピンク = マイナス、金のふち = 前の世代から変わった重み
- **観測記録**: 「餌のにおいへ曲がるようになった」「クラゲを感じると光るようになった」など、本能に起きた変化を自動で見つけて記録

## しくみ（技術メモ）

### 1粒の体と本能
- 4つの感じる場所（ここ・前・左前・右前）で、場（餌・仲間の光・群れの密度）・岩までの距離・外の光・クラゲの振動を読む
- 入力は **左右対称** に作る: 偶の入力（ここの強さ・前とここの差・自分の速さ・元気）と、奇の入力（左 − 右）
- 隠れ層 h = tanh(We·xe + Wo·xo + b) と、鏡に映した h' = tanh(We·xe − Wo·xo + b) を両方計算し、
  旋回 = Σ v(h − h') ＋ 近道、速さ = sigmoid(Σ u(h + h') ＋ 近道)、発光 = clamp(Σ u(h + h') ＋ 近道, 0, 1)
  → 「右の危険を左へよける」と「左の危険を右へよける」が同時に身につく
- 近道（入力 → 出力の直接の重み）があるので、「危険を感じたら光る」のような単純な反射は1つの重みで身につく
- 神経 8 → 12 → 16。感覚がふえたとき、前の試練の本能はそのまま受けつぎ、ふえた重みは 0（ふえた神経は小さな入力の重みだけ）から始める

### 進化戦略（`js/ml/snes.js`, `js/ml/evolve.js`）
- **SNES**（分離型自然進化戦略, Schaul ほか 2011）: 重みごとに平均 μ とゆらぎ σ を持つ
- 1世代 = 中心 μ ＋ 最高記録 ＋ 鏡あわせの変異 μ ± σε を 7 組 = 16 個を **同じ乱数の同じ海** で走らせる（成績の差 = 本能の差）
- 順位から重み（utility）を作り、μ ← μ + σ ⊙ Σ u ε、σ ← σ ⊙ exp(η/2 · Σ u (ε² − 1))
- いまの本能が最高記録より大きく劣る世代が続いたら、最高記録へ戻す
- 次の試練は前の試練の最高記録から始まる。受けついだ重みの σ は小さく（0.1）、新しい感覚・神経の重みの σ は大きく（0.4、近道は 0.8）して、身についたくせを忘れずに新しい器官の使い方を探す
- 試練ごとに海（餌場の位置・クラゲの出発点・月のリズムの速さ）は毎世代かわる → どんな海でも通じる本能が残る

### GPU（`js/sim/shaders.js`, `js/sim/swarm.js`）
WebGL2 のフラグメントシェーダーで、全粒子の本能をいっせいに計算します（ビルド不要、外部ライブラリなし）。

1ステップ = 4 パス:
1. **粒子の更新**: 粒の状態（RGBA32F テクスチャ × 3、MRT）を読み、場をサンプリング → 本能（重みは世界ごとに1行のテクスチャ）→ 動く・食べる・光る・食べられる → 書きこむ
2. **場へ落とす**: 粒を点として描き、加算合成で「群れの密度・食べた量・発光」を格子（RGBA16F）へ
3. **場の更新**: 光は減衰しながらにじむ、餌は食べられて再生、密度はぼかす
4. **捕食者の更新**: クラゲは密度の高い方へ向かう。まぶしい光（場の光）がにがて

- 16 の世界は1枚のテクスチャに並べたタイル。粒は世界ごとのブロック（学習 32×32 = 1,024粒、本番 512×256 = 131,072粒）
- 場の値は粒の数で割ってそろえてあるので、1,024粒で学んだ本能が十万粒でも同じように「混雑」「光」を感じる
- 成績は粒ごとに積算し、世代の終わりにブロックごとの和（段々の縮約）を読み出す
- iOS の Apple GPU の制約に合わせて、MRT は RGBA32F × 3（384bit/px）、ブレンドする場は RGBA16F

### 試練の工夫
- **岩の迷路**: 外の光は「海面まで水の中を通る道のり」で決まる（岩はさえぎる）。光の勾配は、すきまへ向かう道を指す
- **光のことば**: 発光は、クラゲに食べられそうなとき相手をひるませる（夜光虫の実際の防御: 驚かせ効果）。まわりが明るいとクラゲは目がくらんで食べられず、強い光の場からは逃げていく。ただし光るのは高くつき、ずっと光っていると飢える。
  ためしに手で作った本能で比べると（4つの海の平均）: 逃げるだけ 83% → 危険を感じたら光る 98% → ずっと光る 43%。「必要なときだけ光る」理由がはっきりあるので、進化がそれを見つけられる
- **月のリズム**: 洞窟の天井の穴から月の光が差し、すみの方ほどかすかになる。月が明るいときに光り暗いときに消えるほど成績が上がる（光りっぱなしは0点）。ほかの試練とちがい生きのびるのはやさしく、成績はほぼリズムで決まる

## 学習できることの確認（ヘッドレスの Chromium ＋ SwiftShader で実際に進化させた例）

| 試練 | 始まり | 進化のあと | 世代 |
| --- | --- | --- | --- |
| 1. 熱水の揺りかご | 生存 0%（全員が飢える） | 生存 約 60% | 約 6 |
| 2. 岩の迷路 | 成績 0.59（岩の下で止まる） | 成績 2.3（ほぼ全員が出口へ） | 約 12 |
| 4. 光のことば（3 から受けつぎ） | 生存 71%・発光 0 | 生存 約 95%・危険なときだけ光る | 約 20 |
| 5. 月のリズム | 同調 0% | 同調 約 79% | 約 24 |

（1つの世界 256 粒での実験。ゲームでは 1,024 粒なので、成績のぶれはもっと小さい）

## ファイル構成

```
noctiluca/
  index.html  css/app.css  manifest.json  sw.js  icons/
  js/main.js              起動・画面の切りかえ・描画ループ
  js/gl/gpu.js            WebGL2 の道具（シェーダー・テクスチャ・FBO）
  js/sim/                 粒子シミュレーション（シェーダー・群れ・本能の形・試練・岩と光の地図）
  js/ml/                  進化戦略（SNES・並列世界での進化）
  js/gfx/render.js        描画（深海・粒・クラゲ・残像）
  js/game/                物語・保存・学習セッション・本能の観測
  js/ui/                  画面（タイトル・海の地図・進化・本番・ラボ・しくみ）とグラフ
  tools/                  開発用スクリプト
```

## 開発用スクリプト

```bash
python3 tools/build_sw.py            # ファイルを変えたら Service Worker のキャッシュ一覧を更新
node tools/make_icons.mjs            # アイコンを作る
node tools/run.mjs "tools/evotest.html?stage=signal&gens=40"   # ヘッドレスのブラウザで進化させて学習曲線を見る
node tools/shots.mjs "tools/view.html?stage=jelly&gens=10" out/  # 学習させてモザイクと本番の絵を撮る（pre=jelly:20 で受けつぎ、row=… で保存した本能）
node tools/run.mjs "tools/ablate.html?stage=signal&seeds=4"      # 手作りの本能をくらべて、試練のつり合いを確かめる
node tools/ui.mjs "index.html?safe=47,34&screen=evolve" out.png  # 画面を撮る（?safe= で iPhone 12 のノッチを再現）
```

URL パラメータ: `?screen=map|evolve|show|lab|how`、`?arg=試練のid`（例 `?screen=show&arg=jelly`）、`?safe=47,34`
