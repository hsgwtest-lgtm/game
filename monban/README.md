# 門番の目 — 手法で変わる学習パズル

門番に見本を見せて「止める・通す」を教える機械学習パズルです。
同じ見本でも、**線形・決定木・k近傍法・ニューラルネット・森** のどれで学ばせるかで、頭の上に育つ「脳」の形も、本番での強さも変わります。iPhone の PWA として遊べます。

`https://hsgwtest-lgtm.github.io/game/monban/`

## あそびかた

1. 列に並んだ訪問者をタップして **見本** にする（数に上限あり）。頭の上の札が答え（○ 通す／× 止める）
2. **手法** と **レンズ**（門番が見る特徴）を選ぶ。門番はその場で学び直す
3. **本番へ**。はじめて見る訪問者30体を、門番がひとりで仕分ける

- ★ 合格　★★ 正解率90%以上　★★★ それを少ない見本で
- 結果の画面で「同じ見本・同じレンズで、ほかの手法ならどうだったか」を比べられる

## 画面の見かた

| 場所 | 中身 |
| --- | --- |
| 右上「門番の目」 | 門番の目の位置から見た映像。いま見ている相手が映る |
| 門番の頭上の輪（レンズ） | 門番が見ている特徴。中の丸の大きさが、いまの相手の値 |
| レンズから上の線と丸（脳） | 手法ごとに形が違う。線は見本を足すたびにレンズから生え直す |
| 左上「頭の中の地図」 | レンズ2つを横と縦にとった塗り分け。タップで組み合わせを切り替え |
| 足もとの輪 | 門番のいまの答え。札と食いちがう相手には黄色い「？」 |

訪問者の6つの特徴は姿にそのまま出ます: 赤さ（体の色）・大きさ・角（本数）・速さ（ゆれる速さと前のめり）・光・高さ（浮き）。

## 5つの手法（すべてブラウザの中で学習。外部ライブラリなし: `js/ml/models.js`）

| 手法 | 中身 | 脳の形 | つまみ |
| --- | --- | --- | --- |
| 線形 | ロジスティック回帰（最急降下法） | レンズ→出力へ線1本ずつ。太さ＝重み | なし |
| 決定木 | ジニ不純度で分ける木 | 質問の四角と答えの丸。相手がたどる道が光る | 深さ 1〜4 |
| k近傍法 | 見本を丸ごと覚えて多数決 | 覚えた見本の丸。似ている k 体へ線が伸びる | k = 1/3/5 |
| ニューラルネット | 中間層1つ（tanh）、Adam で700歩 | レンズ→中間→出力。学習中は線の太さが動く | 中間の数 2/4/8 |
| 森 | 切る位置を乱数で決めた木の多数決 | 木1本が三角1つ。色がその木の票 | 木の本数 5/9/15 |

線の色: 赤むらさき＝「止める」へ押す／緑＝「通す」へ押す。

## 長く遊ぶための仕組み

- **キャンペーン 30門**（5章×6）。章の最後の門を合格すると新しい手法がもらえる
- **★3** と **手法スタンプ**（門ごとに、合格した手法を記録）
- **日替わりの門**: 日付で決まる出題。ルールは秘密で、結果の画面で明かされる。点数と連続日数を記録（6番の門を合格で開く）
- **夜勤**: 手札は毎回2枚だけ。門を越えるほど難しくなる。ミスで♥が減り、なくなるまでの点数を競う（12番の門を合格で開く）

## つくり

| --- | --- |
| `js/main.js` | 画面の切り替えと遊びの流れ |
| `js/ml/models.js` | 5つの学習手法 |
| `js/game/rules.js` | 特徴、ルール（止める条件）、訪問者の作り方 |
| `js/game/stages.js` | 30門の定義 |
| `js/game/level.js` | 出題づくり（見本の列がルールを伝えきれるまで作り直す）と採点 |
| `js/game/gen.js` | 日替わり・夜勤の出題 |
| `js/game/save.js` | 記録（localStorage、この端末の中だけ） |
| `js/gfx/scene.js` | 3Dの舞台（Three.js r186 を `lib/` に同梱）と「門番の目」の小窓 |
| `js/gfx/brain.js` | 手法ごとの脳の表示 |
| `js/gfx/visitor.js` | 訪問者の姿 |
| `js/ui/map.js` | 頭の中の地図 |
| `css/app.css` | 画面まわり。色・角丸・文字はデジタル庁デザインシステムのデザイントークン（MIT）を使用 |
