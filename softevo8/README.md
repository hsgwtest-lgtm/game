# SoftEvo 8 — 進化観察ラボ

softevo7 の「自分が作った生物の進化を、ニューラルネットワークを通して観察できる」体験を核に、
ゼロから設計し直した新作です。ビルド不要・外部依存なし（ES Modules + Web Worker + Canvas）、PWA 対応。

```
softevo8/
├─ index.html / style.css / manifest.json / sw.js / icons/
└─ js/
   ├─ sim.js        決定論的な物理 + 脳 (Worker と画面で共有)
   ├─ evo.js        遺伝的アルゴリズム + 系統(クレード)追跡
   ├─ worker.js     進化をバックグラウンドで回し続ける
   ├─ app.js        画面の流れ・物語(ジャーナル)・保存
   ├─ builder.js    生物エディタ
   ├─ theater.js    劇場 (再生・ゴースト・パレード・脳の手術)
   ├─ brainview.js  脳の可視化
   ├─ charts.js     推移グラフ / 歩容図 / ミュラー図
   ├─ world.js      世界と生物の描画
   ├─ store.js      保存・書き出し
   └─ ui.js         小さなUI部品
```

## 何が大事だと考えたか

| ユーザーが本当に欲しいもの | SoftEvo 8 での答え |
|---|---|
| **一世代ずつじっくり見たい／待たずに進めたい** | 既定は「▶ 観察」: 再生1回につき1世代ずつ進化。「⏩ 高速」にすると Web Worker で全力実行（デスクトップで毎分数百世代） |
| **でも一匹一匹をちゃんと見たい** | 物理が完全に決定論的なので、Worker が評価した個体を画面上で**寸分違わず再現**できる。「劇場」は各世代のチャンピオンを再生し、同世代のライバルをゴーストで重ねる |
| **脳と体のつながりを理解したい** | 入力ニューロンに「筋3 伸び」「点2 接地」など意味のある名前。筋肉と出力ニューロンを同じ色で統一。ニューロンをタップ→体の部位が光る、体の筋肉をタップ→対応ニューロンが選ばれる |
| **脳が「何をしているか」を確かめたい** | 🔪 **ノックアウト（脳の手術）**: ニューロンを止めると、走っている最中の個体の動きが変わる。因果関係を自分の手で実験できる |
| **進化で何が変わったのか知りたい** | 脳の **変異モード**: 親からどのシナプスが変わったかをピンク/紫で表示 |
| **進化の物語を感じたい** | 「はじめて前進」「5m の壁を突破」「大躍進」「新しい動き方を発見」「新系統誕生」「系統が集団を制覇」「停滞→変異強化」「環境変化」を自動で検出して **物語（ジャーナル）** に記録。タップでその世代へ |
| **成長をひと目で実感したい** | **パレード**: 第0世代・節目の世代・最新世代をレーンに並べて同時に走らせる |
| **動きのリズムを見たい** | **歩容図**: 筋肉の収縮と足の接地を楽譜のように表示。歩き方が確立すると模様が規則的になる |
| **集団の中の「血筋」を見たい** | 記録を大きく更新した個体が新系統の祖になり、子孫が系統を受け継ぐ。**ミュラー図**で系統の盛衰が見える |
| **環境への適応を見たい** | 途中で地形(平地/丘陵/でこぼこ/階段)・目標(距離/省エネ/跳躍)・重力・摩擦を変更可能。推移グラフに境界線が入る |
| **作るのは簡単に** | タップでノード、ドラッグで骨/筋肉。空白までドラッグすると新ノードごと伸びる。左右対称モード、元に戻す、プリセット、ランダムな脳での試運転 |
| **失くしたくない** | 25世代ごと・画面を離れる時に自動保存。JSON 書き出し/読み込み |

## 物理エンジンについて

- Verlet 積分。**骨**は剛体拘束、**筋肉**はバネ（中心力）として実装。
  位置拘束で筋肉を解くと、骨と筋肉がせめぎ合った時に角運動量が湧き出す「数値的な永久機関」が生まれ、
  生物が宙を回転して秒速 8m で飛んでいく不正解が進化してしまうため。
- 筋肉は瞬時には動けない（ローパス）ので、振動の悪用が起きにくく動きも有機的。
- 結果として、二足は直立して左右の足を交互に接地する歩行、四足はトロット状の歩容に自然に進化する。

## 脳の入力

| グループ | 内容 |
|---|---|
| 筋の伸び | 各筋肉の現在長 / 静止長（固有感覚） |
| 接地 | 各ノードが地面に触れているか（足裏の感覚） |
| 姿勢/速度 | 体全体の傾き (sin, cos)、重心の速度 (→, ↑) |
| リズム | 脳内の振り子 (sin, cos)。周期は遺伝子で進化する |

出力は筋肉ごとに 1 ニューロン（tanh）。隠れ層は 1〜2 層で大きさは設計画面で変更可能。
