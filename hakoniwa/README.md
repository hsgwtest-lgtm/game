# はこにわ進化島 — ドットの生態系

ドットの小さな島で、**草 → 草食動物 → 肉食動物** の食物連鎖が回る、生態系と進化の観察ゲームです。
生き物は1匹ずつ自分の小さな脳（自作のニューラルネット）で考えて動き、子に**形質と脳の重み**を受け継ぎます。世代を重ねると、島の環境に合った体と行動が残っていく様子（自然選択）が、グラフと島の上の色で見えます。

- 公開URL: `https://hsgwtest-lgtm.github.io/game/hakoniwa/`
- iPhone 12 Pro の縦画面・タッチ操作向けの PWA（ホーム画面に追加でき、一度開けばオフラインでも遊べます）
- 外部ライブラリは Three.js だけ（`lib/` に同梱）。機械学習ライブラリは使っていません

| 👆 観察 | 生き物をタップ | 体力・行動・形質・**脳の中（入力→中間→行動）**を表示。視野の輪とねらいの線も出る |

| 🔥 熱波 / ❄️ 寒波 | ボタン | 気温が上がる／下がる。暑さ・寒さに弱い個体が苦しみ、子を作れなくなる（寒波では雪が積もる） |

### パネル

- 📈 グラフ … 個体数（草食・肉食・種ごと・草の量）と、**形質の平均・ばらつき・いまの分布**の推移
- 🧬 種 … 生きている種／絶滅した種の一覧（祖先・世代・平均形質）と、できごとの記録
- 🏆 ミッション … いまの目標と進み具合（観察モードではミッション一覧）
- ☰ メニュー … 形質で色分け（速さ・大きさ・視野・食性・耐寒性）、ドットの大きさ、影、突然変異の強さ、保存、タイトルへ

## 生態系のしくみ

### 食物連鎖

- **草**は土の肥えた場所ほどよく育ち、食べられて短いほど早く伸びる。昼・雨で育ち、寒さ・暑さ・雪で育たない
- **木**は木の実を落とす。木の実はしばらくすると腐って土の養分になる
- **草食動物**は草と木の実を食べる。**肉食動物**は草食動物を狩り、亡きがらも食べる
- 死んだ生き物は土に還り、そこの草がよく育つ
- 肉食は山頂に登れない（草食の逃げ場）。森の中や休んでいる草食は見つかりにくい

### 脳（`js/brain.js`）

全個体が、12入力 → 中間8（tanh）→ 5出力 の小さなニューラルネットを持っています。0.25秒ごとに入力を計算し、点数がいちばん高い行動を選びます（いまの行動を少しだけ続けやすくしている）。

| 入力（12） | 出力（5つの行動） |
| --- | --- |
| 体力、餌の近さ、敵の近さ、仲間の近さ、混み具合、足元の餌、暗さ、暑さ寒さ、年齢、繁殖できるか、雨、気まぐれ | うろうろ・食べる・逃げる・繁殖・休む |

最初の世代には「お腹がすいたら食べる」「敵が近いと逃げる」程度の本能を重みとして与え、そこにゆらぎを足しています。重み149個はそのまま遺伝子です。

### 遺伝と突然変異（`js/genetics.js`）

| 形質 | 範囲 | 得すること | 損すること |
| --- | --- | --- | --- |
| 速さ | 0.4〜2.2 | 逃げきれる・追いつける | 走るほどエネルギーを使う（速さの2乗） |
| 大きさ | 0.5〜2.0 | 体力の貯え、狩られにくい／狩りやすい、暑さ寒さに強い | 動くのに疲れる、大人になるのも子作りも遅い |
| 視野 | 2〜10 | 餌や敵を遠くから見つける | 見張るのにエネルギーを使う |
| 食性 | 0〜1 | 草食: 0＝草が得意、1＝木の実が得意／肉食: 0＝雑食、1＝肉の栄養をよく取れる | 反対側の食べ物が苦手になる |
| 耐寒性 | 0〜1 | 寒さに強い（1）／暑さに強い（0） | 合わない気温ではエネルギーを使い、子を作れない |

- 子は親の形質と脳の重みを受け継ぎ、少しずつ突然変異します。近くに同じ種の相手がいれば、2匹から受け継ぐこともあります
- 形質が祖先（種の最初の個体）から一定以上離れた子が生まれると、**新しい種**として名前がつきます（例: ハヤノハラネズミ＝足が速く、草原の草を食べる小さな種）

### 時間と天気

1日は1倍速で120秒。朝・昼・夕方・夜がめぐり、夜は草食の視野がせまくなります。雨はときどき自然にも降ります。

## ミッション（`js/missions.js`）

| | 名前 | 目標 | 期限 |
| --- | --- | --- | --- |
| ⚖️ | はじまりの均衡 | 肉食が多めの島で、草食・肉食を絶滅させずに10日間守る | なし |
| 💨 | 俊足の血統 | 草食の種のどれか1つ（8匹以上）の平均の速さを1.85以上にする | 30日 |
| ❄️ | 雪国の毛皮 | 寒い島で、草食（10匹以上）の平均の耐寒性を0.68以上にする | 30日 |
| 🧬 | 多様性の島 | 動物の種を6種以上（どれも4匹以上）、同時に2日間保つ | 40日 |
| 🌱 | 荒れ島の再生 | 荒れた島で、草食40匹以上・肉食6匹以上を同時に1日間保つ | 25日 |

達成した記録はタイトル画面の「ミッションに挑戦」に★で残ります。達成・失敗のあとは、そのまま観察モードで島を見続けることもできます。

## コミットから公開まで

GitHub Pages は `main` ブランチの内容をそのまま公開しています（このリポジトリの `Settings → Pages` で、Source が `main` / `/(root)` になっていること）。

### プルリクエストから公開する場合

1. GitHub でプルリクエストを開き、「Files changed」で `hakoniwa/` の中身を確認する
2. 「Merge pull request」→「Confirm merge」で `main` に取り込む
3. 数分待つと GitHub Pages が自動で再公開される（`Actions` タブの「pages build and deployment」が緑になれば完了）
4. `https://hsgwtest-lgtm.github.io/game/hakoniwa/` を開いて確認する

### 手元からコミットする場合

```bash
git clone https://github.com/hsgwtest-lgtm/game.git
cd game
# hakoniwa/ フォルダを置く（または編集する）
git add hakoniwa
git commit -m "はこにわ進化島を追加"
git push origin main
```

push のあと、上の手順3・4と同じように公開を確認します。

### iPhone でアプリとして使う

1. Safari で公開URLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 一度開けば全ファイルが端末に保存され、機内モードでも遊べます

### 手元のパソコンで確認する

`file://` では動かないので、リポジトリの一番上で簡単なサーバーを立てて開きます。

```bash
python3 -m http.server 8000
# → http://localhost:8000/hakoniwa/
```

## 更新するとき

- ファイルを直したら、`sw.js` の先頭の `VERSION`（例: `'v1'` → `'v2'`）を必ず上げてください。上げないと、一度開いた端末には古い版が残ります
- ファイルを増やしたら、`sw.js` の `ASSETS` にも相対パスで追加してください
- キャッシュ名は `hakoniwa-` で始まり、同じ `hsgwtest-lgtm.github.io` にあるほかのアプリのキャッシュは消しません

## PNG アイコンを追加するとき

`icon.svg` から 192×192 と 512×512 の PNG を作り（例: `icons/icon-192.png`、`icons/icon-512.png`）、次のように書き足します。iPhone のホーム画面のアイコンは PNG が必要です。

`manifest.webmanifest` の `icons`:

```json
{ "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png" },
{ "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png" },
{ "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
```

`index.html` の `<head>`（`apple-touch-icon` を置きかえる）:

```html
<link rel="apple-touch-icon" href="icons/icon-192.png">
```

`sw.js` の `ASSETS` に `'./icons/icon-192.png'` と `'./icons/icon-512.png'` を足し、`VERSION` を上げます。

## 保存データ

この端末のブラウザの localStorage に保存します（ほかの端末には送りません）。

| キー | 中身 |
| --- | --- |
| `hakoniwa:save:v1` | いまの島（地形のシード、草、木、木の実、全個体の形質と脳、種、グラフの記録、ミッションの状態）。約20秒ごと・アプリを閉じたときに自動保存 |
| `hakoniwa:prefs:v1` | 設定（色分け・ドットの大きさ・影・速さ）とミッションの達成記録 |
