# BIT BIRDS — AIヒナ そだてラボ

ピクセルの目をもつAIのヒナが、**遺伝的アルゴリズム（進化）** と **模倣学習（まねっこ）** で
空の飛び方を覚えていく、全画面ドット絵の機械学習ゲームです。iPhone の PWA として遊べます。

## あそびかた

| モード | 中身 | 使っている機械学習 |
| --- | --- | --- |
| **そだてる** | 50羽の群れが同じコースを飛び、遠くまで飛べた子の脳（DNA）が次の世代へ受け継がれる | ニューロエボリューション（遺伝的アルゴリズム＋ニューラルネット） |
| **おしえる** | 自分で操縦したお手本をヒナがまねして学ぶ。「AIまかせ」で飛ばし、危ない時に指でたすけると苦手な場面を重点的に学ぶ | 模倣学習（ビヘイビア・クローニング）＋ DAgger |
| **きそう** | 群れのエース・教えたヒナ・博士のヒナとレース | 学習済みの脳で対戦 |
| **しくみ** | 目・脳・交叉・突然変異・報酬設計・誤差逆伝播を動くドット絵で解説 | — |

ステージは6つ（ゲート → せまい穴 → 柱の森 → 丸太の川 → 動くゲート → 夜の総合）。
前のステージで学んだ脳がそのまま次に引き継がれるので、転移学習の様子も見られます。

### 学習の過程を「見る」ための画面
- **のう**: 注目しているヒナの「AIの目（7×5の奥行き画像）」、隠れ層の活動、強いつながり、操縦出力がリアルタイムで動く
- **グラフ**: 世代ごとの最高・平均距離の学習曲線、多様性
- **むれ**: 50羽の生死・家系（色）の勢力図・エリート・推し
- **DNA**: 親A＋親B → 子 の重みモザイク。交叉でどちらの親から来たか、突然変異した遺伝子が光る
- **ドット博士**: 記録更新・伸びなやみ・多様性低下などを実況
- おしえるモードでは、あなたの操縦（白）とAIの予測（黄）の比較、誤差の減り方、一致度が見える

### 操作
- 画面のどこでもドラッグ → バーチャルスティックで操縦（PC は矢印キー / WASD）
- 右上の `1X 2X 4X 8X` で速さ、`▶▶|` で高速しんか（世代を一気に進める）
- カメラボタンで「うしろ / まえ / うえ」切り替え
- 歯車ボタン：突然変異の強さ、推しを残す、群れの数、リセット

## しくみ（技術メモ）

### 全画面ドット化
1. Three.js r128 で 3D を **低解像度レンダーターゲット**（iPhone 12 で 195×422 ピクセル）に描画
2. ポストエフェクトで **深度から輪郭線** → **4×4 ベイヤーディザ** → **Endesga 32 パレットに減色**
3. UI は自前のソフトウェアフレームバッファ（`js/gfx/fb.js`）に1ピクセルずつ描画（文字は PixelMplus10 のビットマップ）
4. 3D と UI を **整数倍の最近傍拡大**で画面へ（1仮想ピクセル = iPhone 12 で 6 物理ピクセル）

### ノッチ対応
- `viewport-fit=cover` + `black-translucent` で全画面に描き、`env(safe-area-inset-*)` を読み取って仮想ピクセルに換算
- 上部 HUD はノッチの下から、下部パネルの操作部はホームバーの上に収まるよう配置（ノッチ部分には 3D の空だけが映る）
- テスト用に `?safe=47,34` を付けると iPhone 12 のノッチ（上47pt・下34pt）を再現できる

### AI
- 入力 39 = 目 35（光線 2×2 本平均の「近さ」= exp(−距離/5)）＋ 横速度・縦速度・横位置・高さ
- ネットワーク 39 → 10(tanh) → 2(tanh)、重み 422 個
- 遺伝的アルゴリズム：トーナメント選択、エリート保存、ニューロン単位の交叉、ガウス突然変異、
  ぶつかった時の「穴への近さ」ボーナス（報酬シェーピング）
- 模倣学習：Adam による誤差逆伝播、衝突直前0.5秒のお手本は破棄、たすけたデータは重み2.5倍

## ファイル構成

```
bitbirds/
  index.html  style.css  manifest.json  sw.js  icons/
  lib/three.min.js          Three.js r128（同梱：オフラインで動くように）
  js/main.js                ループ・画面遷移
  js/core/                  定数（ステージ・パレット）、乱数、保存、効果音
  js/gfx/                   ピクセル描画、フレームバッファ、ドット文字、スプライト
  js/sim/                   コース生成、飛行・目・当たり判定
  js/ml/                    ニューラルネット、遺伝的アルゴリズム、模倣学習
  js/world/world3d.js       3D ワールド（渓谷・障害物・鳥・カメラ）
  js/ui/                    入力、UI部品、学習の可視化、スティック
  js/screens/               各画面
  js/game/                  進行状況、博士、デモ飛行、博士のヒナの脳
  tools/                    開発用スクリプト
```

## 開発用スクリプト

```bash
python3 tools/build_font.py      # 文章を変えたらドット文字アトラスを作り直す
python3 tools/build_sw.py        # ファイルを変えたら Service Worker のキャッシュ一覧を更新
python3 tools/make_icons.py      # アイコン生成
node tools/check_imports.mjs     # モジュールの import/export チェック
node tools/train_test.mjs 0,1,2 60   # ブラウザなしで学習できるか確認（ステージ, 世代数）
STAGES=0,1 SEEDS=1,2,3 PM=0.05 SIGMA=0.2 node tools/exp.mjs   # GAの設定を変えて何世代でクリアできるか比べる
node tools/make_demo.mjs         # 「博士のヒナ」の脳を作り直す
node tools/make_demo_robust.mjs 150  # 複数コースの平均でさらに鍛える
python3 tools/bundle_test.py     # 自動テスト用に1ファイルへまとめる（tmp_test/、コミットしない）
```
