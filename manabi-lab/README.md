# 学習くらべラボ

ボクセルの小さな島で、草を食べて暮らす生き物たちが **4つのちがう学び方** で「上手な暮らし方」を身につけていく、ドット絵 × Three.js の実験ラボ（PWA）です。
同じ島・同じ世界ルール・同じ出発地点で走らせるので、「学び方のちがい」だけを取り出してくらべられます。

- 画面は全部ドット調：島は低い解像度で描いてから最近傍で拡大し、色の段階化＋ディザ＋輪郭線をかけています。ボタン・パネル・グラフ・アイコン・数字もドットで描いています。
- iPhone の縦画面・タッチ操作が前提。ホーム画面に追加すると、アプリのように全画面で動きます。
- 初回に開いたときに全ファイルを保存するので、2回目からは **オフラインでも動きます**。外部への通信はありません（Three.js は `lib/` に同梱）。
- 実験はこの端末の中（localStorage）にだけ保存されます。

## はじめかた

`manabi-lab/` フォルダをそのまま静的サーバーで配信して、`index.html` を開きます。

```sh
cd manabi-lab
python3 -m http.server 8000   # → http://localhost:8000/
```

（ES モジュールと Service Worker を使うので、`file://` で直接開くのではなくサーバー経由で開いてください。）

## あそびかた

### 島のきまり（4つの方式すべてに同じ）

- 生き物は毎ターン、**食べる / 北・東・南・西へ歩く / 眠る** の6つから1つを選びます。
- 草を食べると体力が増え、何をしていても体力は減ります（歩くともっと減る）。体力が80をこえると子を産みます。体力がつきるか寿命（約2.5日）で死にます。
- 1日は48ターン。そのうち14ターンが夜です。夜は草が育ちにくく、暗くて草をうまく食べられず、においも1マス先までしか届きません。夜に歩くと **フクロウ** におそわれることがあります（眠っていれば安全）。
- 草は「草むら」と「はげ地」がまだらに生えています。生き物は各方向の **におい**（その方向の草の多さ）を感じられます。

### 1世代 = 1シーズン（3日）

シーズンのはじめに、方式ごとに16匹の **創始者** が同じ場所から出発します。創始者とその子孫を「家族」と呼び、家族が集めた草の量がその創始者の **適応度** です。シーズンが終わると、方式ごとのやり方で次の世代が作られます。

### 2つのくらべ方

| モード | 内容 |
|---|---|
| **4つの島でくらべる** | 方式ごとに別々の島（同じ地形・同じ出発点）。純粋に学び方だけをくらべられる。チップをタップして見る島を切り替える。 |
| **1つの島で競争させる** | 4方式が同じ島で草を取り合う。集めた草の割合（取り分）で、次の世代の創始者の数＝なわばりが決まる。チップをタップすると、その方式だけ明るく表示。 |

### 操作

| 操作 | できること |
|---|---|
| 1本指ドラッグ / 2本指 | 島を回す / ズーム・移動 |
| 生き物をタップ | その個体の「いま何を考えているか」カード（ルールなら使った規則、進化NNなら脳の出した点数、Q学習なら状態とQ表の行、ランダム＋選択ならサイコロの出やすさ） |
| 停止 / 1x / 2x / 4x | 時間の速さ（1x = 1秒に6ターン、1世代24秒） |
| **最大** | **ヘッドレス高速学習**。島の描画をほぼ止めて、1フレームの持ち時間いっぱい学習だけを回す（端末によって毎秒数十世代）。画面中央に世代・世代/秒・学習曲線を表示。タップで元の速さへ。 |
| グラフ | 学習曲線（平均の草・ベスト家族・生存日数・生まれた数・競争モードでは取り分）、行動の獲得（「食べる」「においをたどる」「夜は眠る」を身につけた度合い）、できごとの記録 |
| 系図 | 進化NN・ランダム＋選択の親子のつながり（画面に入るぶんの最近の世代）。黄色い線は「いまいちばんの個体の祖先」。種の分岐を積み上げた「種の川」と、生きている種の一覧 |
| リプレイ | 方式ごとの **ベスト記録** と **最新の世代のベスト** の家族のシーズンを、1ターンも違わずに再生。巻き戻し・早送り（1〜8x）・シーク。主役の創始者は黄色の目印と足あとで追いかける |
| 方式 | それぞれの頭の中：ルールの規則と使われている割合、いちばんの脳の重み91個、Q表の方針地図（144状態）、世代平均のサイコロ。4方式のちがいの一覧表 |
| 実験 | 「+10 / +50 / +200世代」を一気に学ばせる、くらべ方・方式・島のシード・創始者数・日数・学習のこまかい設定（α・γ・ε、突然変異・交叉の確率など）を変えてやり直す、ドットの大きさ、保存 |

島の上では、**方式ごとに色と頭の飾り** がちがいます（ルール＝灰色の四角い帽子、進化NN＝ピンクのアンテナ、Q学習＝水色のゴーグル、ランダム＋選択＝黄色に白いサイコロ）。Q学習の個体が「ためしの一手」（ε による探索）をとった瞬間は、白く光ります。

## 4つの学び方のちがい

| | ルール | 進化NN | Q学習 | ランダム＋選択 |
|---|---|---|---|---|
| まわりを見る | ○ | ○ | ○ | × |
| 生きているあいだに学ぶ | × | × | **○** | × |
| 世代をこえて伝わるもの | なし | 脳の重み91個 | みんなで共有する Q 表 | サイコロの偏り6個 |
| 選択（よい家族を残す） | × | ○ | × | ○ |
| 交叉（親を混ぜる） | × | ○ | × | × |
| 突然変異 | × | ○ | × | ○（コピーのゆらぎ） |
| ためし（探索） | × | 突然変異 | ε-greedy | 毎ターンがでたらめ |

### ① ルール（対照群）

人が書いた決まりで動きます。上から順に調べて、最初に当てはまったものを実行します。

1. 夜で、お腹がすいていなくて、足元に草がない → 眠る
2. 足元に草がある → 食べる
3. においのする方向がある → いちばん強い方へ歩く
4. どれでもない → 通れる方へ気ままに歩く

最初からそこそこ上手ですが、何世代たっても変わりません。ほかの方式が「どこまで来たか」をはかる物差しです。

### ② 進化NN（ニューラルネット＋遺伝的アルゴリズム）

自作の小さなニューラルネット（重み91個）が脳です。体力・足元の草・夜・混雑・気まぐれを見る「全体回路」と、1方向ぶんのにおいを見て「その方向へ歩くか」を決める「方向回路」（北東南西で同じ重みを共有）でできています。
**生きているあいだは何も学びません。** 世代交代のときに、よく草を集めた家族の脳を選び（トーナメント選択・上位2つはそのまま残すエリート）、2つの親の脳をニューロン単位で混ぜ（交叉）、少しだけ変えて（突然変異）次の世代にします。最初はでたらめな脳なので何もできませんが、何十世代かかけて「食べる」「においをたどる」が選び出されていきます。

### ③ Q学習（表形式）

状況を「体力3段階 × 足元の草3段階 × においの方向4 × においの強さ2 × 昼夜2 = 144通り」に分け、状態ごと・行動ごとの「良さ」Q(s,a) を表に書きます。毎ターン、体力の増減を報酬にして
`Q(s,a) ← Q(s,a) + α [ r + γ max Q(s′,·) − Q(s,a) ]`
で書き直します（死んだら罰）。確率 ε でわざとでたらめな行動をとって試し（探索）、ε は世代ごとに小さくなります。
表はその方式の全員で1つを共有し、**生きているあいだに経験から学びます**。選択も遺伝もしません。だから1世代目のうちから目に見えて上手になっていきます。

### ④ ランダム＋選択（学習と選択の切り分け）

まわりを **まったく見ずに** サイコロで行動します。遺伝するのは「どの行動が出やすいか」というサイコロの偏り6個だけ。世代交代で、よく集めた家族のサイコロを選んで、少しゆらぎを加えて写します。
「選択だけで、どこまで行けるか」を見るための対照群です。食べる目が出やすいサイコロは選ばれますが、においをたどることは原理的にできません。

### テストで測ったちがい（`tests/results.json`）

学習を止めた状態で、決まったテスト用シーズン（4シーズン）を走らせて測った「家族あたりの草」です（島シード 7/11/23 の平均、120世代学習）。

| 方式 | 学習前 | 学習後 | 倍率 | ルールの90%に届いた世代 |
|---|---|---|---|---|
| ルール | 14.72 | 14.72 | ×1.00 | （基準） |
| 進化NN | 1.95 | **14.94** | ×7.67 | 第17・17・29世代 |
| Q学習 | 1.61 | 13.81 | **×8.56** | 第4・4・4世代 |
| ランダム＋選択 | 1.23 | 4.22 | ×3.43 | 届かない |

- **速さ**：Q学習は1世代目のうちに学ぶので第4世代でルールの9割に届く。進化NNは選択の積み重ねなので17〜29世代かかる。
- **到達点**：120世代後の腕前は、進化NN（14.94）がルール（14.72）をわずかに上回り、Q学習（13.81）は少し下。
- **感覚の大切さ**：まわりを見ないランダム＋選択は、選択だけでも3.4倍になるが、4.22で頭打ち。
- **身につけた行動のちがい**：Q学習は「夜は眠る」も 0.17 → 0.56 まで覚えたが、進化NNは 0.30 → 0.14 と、むしろ眠らなくなった（そのかわりフクロウに多くやられる：最後の10世代で1世代あたり 12.2 匹、Q学習は 2.8 匹）。

くわしい分析は、このフォルダの1つ上の `PROGRESS.md` にあります。

## ファイル構成

```
manabi-lab/
├── index.html            画面の骨組み
├── style.css             全部ドット調のスタイル
├── manifest.webmanifest  PWA の設定
├── sw.js                 Service Worker（初回に全ファイルを保存 → オフラインで動く）
├── icon.svg              ドット絵のアイコン（32×32）
├── lib/three.module.min.js  Three.js r186（同梱・MIT）
├── js/
│   ├── main.js      入口。ループ・速さ（最大＝ヘッドレス高速学習）・リプレイ・保存
│   ├── render.js    Three.js の描画（低解像度＋最近傍拡大＋ディザ＋輪郭線）
│   ├── ui.js        HUD・チップ・シート（グラフ/系図/リプレイ/方式/実験）・個体カード
│   ├── charts.js    ドットで描くグラフ（学習曲線・系図・種の川・Q表・脳・サイコロ・リプレイ・取り分）
│   ├── icons.js     9×9 のドット絵アイコン（自動でふち付き）と 3×5 のドット文字
│   ├── input.js     タッチ操作（回転・ズーム・移動・タップ）
│   │   ── ここから下は、ブラウザに依存しない純粋モジュール（Node のテストでもそのまま動く）
│   ├── sim.js       島と実験全体（世代・適応度・競争モード・保存）
│   ├── world.js     地形・草・昼夜・世界のルール
│   ├── methods.js   4つの方式（行動の決め方と、世代をこえた学び方）・行動テスト
│   ├── nn.js        自作ニューラルネット（重み91個）
│   ├── ga.js        遺伝的アルゴリズム（トーナメント選択・エリート・交叉・突然変異）
│   ├── qlearn.js    表形式 Q 学習（144状態 × 6行動）
│   ├── species.js   種の判定と分岐の記録
│   ├── replay.js    ベスト個体のリプレイ（決定的な再シミュレーション）
│   ├── evaluate.js  腕前テスト（学習を止めて測る）
│   ├── defs.js      行動・感覚・方式の定義
│   └── util.js      種つき乱数など
└── tests/
    ├── run.js           テストの入口
    ├── unit.test.js     単体テスト（乱数・地形・NN・GA・Q学習・種・シミュレーション・保存・リプレイ）
    ├── shell.test.js    PWA の外側の点検（オフライン用の保存リスト・id・アイコン・ドットのグラフ）
    ├── bench.test.js    ベンチマーク「餌集め」（4方式 × 島シード3つ × 120世代 ＋ 競争モード）
    └── results.json     ベンチマークの結果
```

## テスト

```sh
cd manabi-lab
node tests/run.js          # 単体テスト＋PWAの外側の点検＋ベンチマーク（結果を tests/results.json に保存）
node tests/run.js --unit   # 単体テスト＋PWAの外側の点検だけ
node tests/run.js --bench  # ベンチマークだけ
```

依存パッケージはありません（Node 18 以上）。乱数はすべて種つきなので、何度実行しても同じ数値になります。
「実験」→「テストと同じ条件」で始めると、アプリの中でもベンチマークと同じ条件（4方式・別々の島・シード7・16匹・3日）で観察できます。
