# DOT DOJO — AI三流派 修行録

浮き島の道場で、AIの「でし」を **3つの流派** で鍛える、全画面ドット絵の機械学習ゲームです。
同じ修行場・同じ目・同じ形の脳で、**学び方だけ** がちがう3つの流派をくらべて遊べます。iPhone の PWA として遊べます。

`https://hsgwtest-lgtm.github.io/game/dotdojo/`

## 3つの流派

| 流派 | 師範 | 使っている機械学習 | 手がかり | かかった数の単位 |
| --- | --- | --- | --- | --- |
| **進化流** | カメ仙人 | 遺伝的アルゴリズム（ニューロエボリューション） | 挑戦の最後の成績だけ | 挑戦したでしの人数 |
| **強化流** | サル師範 | 強化学習（PPO：方策勾配＋価値の見積もり） | 1歩ごとのごほうびとばつ | 挑戦した回数 |
| **模倣流** | オウム先生 | 模倣学習（ビヘイビア・クローニング＋DAgger） | あなたのお手本 | 人が教えた歩数 |

修行場で「巻物」を取れる脳に育つと、その流派の **免許皆伝（印）** がもらえます。修行場は9つ × 3流派 = 27の印。

## 修行場（それぞれ流派のちがいが出るように作ってあります）

| # | 修行場 | しかけ | 分かること |
| --- | --- | --- | --- |
| 1 | はじめの一歩 | 穴 | どの流派でも解ける。ちがいは「かかった数」 |
| 2 | ほそい橋 | 落ちたら終わりのジグザグ橋 | 試す流派は回数がかかり、お手本なら一発 |
| 3 | オニの見回り | 往復するオニ | タイミングを読む。「目」にオニの次の位置が映る |
| 4 | カギとトビラ | カギを取るとトビラが開く | 巻物だけをほめると、カギの大切さに気づけない（ほうびの設計） |
| 5 | 小判のわな | 何度でも取れる小判 | 小判のほうびが大きいと巻物を取りに行かない（ごほうびのハック） |
| 6 | トゲの回廊 | 交互に出るトゲ | 「待つ」も大事な一手 |
| 7 | 毎回ちがう庭 | スタート地点が毎回かわる | お手本で見ていない場面に弱い → まかせて手助け（DAgger） |
| 8 | まよいの竹林 | 近づくと行き止まり | 「近づいたらほめる」の落とし穴 → 「はじめての場所をほめる」で探検 |
| 9 | 卒業試験 | ぜんぶ | まねしてから鍛える「合わせ技」 |

ブラウザなしで3流派を回した結果の一例（`node tools/check_sessions.mjs`、ヒントどおりのごほうび設定。乱数で毎回かわる）:

```
1.はじめの一歩  進化 560人  | 強化 368回 | 模倣 9歩
2.ほそい橋      進化 400人  | 強化 400回 | 模倣 15歩
4.カギとトビラ  進化 1760人 | 強化 416回 | 模倣 12歩   ※カギのごほうび0のままだと強化は解けず、進化も何倍もかかる
5.小判のわな    進化 1280人 | 強化 304回 | 模倣 11歩   ※小判のごほうびそのままだと、進化・強化は小判集めに夢中になる
7.毎回ちがう庭  進化 4160人 | 強化 368回 | 模倣 16歩（お手本1回＋手助け8回）
9.卒業試験      進化 2200人 | 強化 672回 | 模倣 15歩   ※模倣→強化の合わせ技なら、強化は1ラウンド目から本番合格
```

## 学習の過程を「見る」ための画面

- **3D の修行場**：群れ・分身・でしが同時に走る。ゴールの花火、落下、オニにやられる様子
- **方針の矢印**（右上ボタン）：いまの脳が各マスで選ぶ行動。自信が強いほど白く大きい
- **ねだん（価値）マップ**（強化流）：「ここからだと、ごほうびがもらえそう」がゴールから広がっていく
- **足あと**：注目しているでしの道。世代・ラウンドの合間にはチャンピオン（進化）・本番テスト（強化）の道
- **グラフ**：成績（最高・平均）、ゴール率、迷い（エントロピー）、誤差（模倣）
- **むれ / DNA**（進化流）：40人の生死と家系の色、親A・親Bからどのニューロンを受けついだか、突然変異
- **のう**：でしの目（5×5）・ゴールの方角・隠れ層16個の活動・行動5つの確率
- **AIの気持ち**（模倣流でまかせ中）：AIが押したいボタンの確率。迷ったら十字ボタンで手助け
- **師範の実況**：記録更新・伸びなやみ・ごほうびのハック・こわがって動かない…を見つけて教えてくれる
- **三流派くらべ**：育てた脳を同じ修行場で同時に走らせる。「鏡の島」（左右反転）で応用力も試せる
- **記録帳・しくみ**：かかった数の比較、3つの学び方を動くドット絵で解説

## 操作

- 下のタブで表示を切り替え、`1x/2x/4x/8x` で速さ、`一気に進化 / 一気に学習` で高速修行
- 3Dのでしをタップすると、そのでしに注目（脳・足あと・矢印がそのでしの視点になる）
- 模倣流：十字ボタン（まんなか＝まつ）か、3Dの画面をスワイプでお手本。長押しで連続移動
- 合わせ技：進化流「模倣流のでしを群れに入れる」、強化流「模倣流の脳から始める」

## しくみ（技術メモ）

### 全画面ドット化（BIT BIRDS と同じ方式）
1. Three.js r128 で 3D を **低解像度レンダーターゲット**（iPhone 12 で 195×約250 ピクセル）に描画
2. ポストエフェクトで **深度から輪郭線** → **4×4 ベイヤーディザ** → **Endesga 32 パレットに減色**
3. UI は自前のソフトウェアフレームバッファに1ピクセルずつ描画（文字は PixelMplus10 のビットマップ）
4. 3D と UI を **整数倍の最近傍拡大** で画面へ（1仮想ピクセル = iPhone 12 で 6 物理ピクセル）

### ノッチ対応
- `viewport-fit=cover` + `black-translucent` で全画面に描き、`env(safe-area-inset-*)` を仮想ピクセルに換算
- 上の HUD はノッチの下から、下の操作ボタンはホームバーの上に配置。3D の島はその間に自動で収まるようにカメラを合わせる
- テスト用に `?safe=47,34` で iPhone 12 のノッチ（上47pt・下34pt）を再現できる

### AI（3流派共通）
- 世界：グリッドの浮き島。行動は ↑↓←→・まつ の5つ。オニやトゲは時刻だけで決まる（群れ全員が同じ時計で走れる）
- 目：まわり5×5マス × 4チャンネル（かべ・きけん・巻物・アイテム）＋ ゴールの方角・カギ・位置 = 入力105
  - 「きけん」には穴・次に出るトゲ・オニの次の位置が映る
- 脳：105 → 16(tanh) → 5、重み 1,781 個（進化流ではこれがそのまま DNA）
- ごほうび：巻物 +10、やられる −1、1歩 −0.02、近づくと +0.3（形づけ）。修行場によって カギ・小判・探検ボーナスを画面で変えられる

### 流派ごと
- **進化流**：群れ20/40/80、トーナメント選択（5人）、エリート保存、ニューロン単位の交叉、ガウス突然変異（弱/中/強）、推しを残す
- **強化流**：分身8/16/32 が同じ脳で並列に挑戦 → GAE(γ=0.96, λ=0.9) → PPO（クリップ0.2、4エポック）＋価値ネット。好奇心＝エントロピーボーナス。学習はミニバッチごとにフレームへ分けて画面が止まらないようにしている
- **模倣流**：Adam で交差エントロピー最小化。ぶつかった操作と落ちる直前2歩のお手本は捨てる。まかせ中の手助けは重み3倍で記録（DAgger）
- 免許皆伝の判定：いちばん自信のある行動だけで、すべてのスタート地点からゴールできること

## ファイル構成

```
dotdojo/
  index.html  style.css  manifest.json  sw.js  icons/
  lib/three.min.js          Three.js r128（同梱：オフラインで動くように）
  js/main.js                ループ・画面遷移
  js/core/                  定数（流派・パレット・テーマ）、乱数、保存、効果音・BGM
  js/gfx/                   ピクセル描画、フレームバッファ、ドット文字、スプライト
  js/sim/                   修行場の定義、グリッドの世界、最短ルート探索、本番テスト
  js/ml/                    ニューラルネット＋Adam、遺伝的アルゴリズム、PPO、模倣学習
  js/world/world3d.js       3D の浮き島（鳥居・オニ・トゲ・カギ・小判・でし・矢印・足あと）
  js/game/                  修行の進行（流派ごと）、進み具合と保存、師範の実況
  js/ui/                    入力、UI部品、学習の可視化
  js/screens/               各画面
  tools/                    開発用スクリプト
```

## 開発用スクリプト

```bash
python3 tools/build_font.py        # 文章を変えたらドット文字アトラスを作り直す
python3 tools/build_sw.py          # ファイルを変えたら Service Worker のキャッシュ一覧を更新
python3 tools/make_icons.py        # アイコン生成
node tools/check_imports.mjs       # モジュールの import/export チェック
node tools/check_sessions.mjs      # ゲームと同じ進行で、全修行場×3流派の印が取れるか確認
NOREC=1 node tools/check_sessions.mjs kagi,koban ga,rl   # ごほうびそのままだと解けないことの確認
node tools/lab.mjs ippo --show     # 修行場の地図と最短ルート
node tools/lab.mjs hashi --ga --rl --il --seeds 1,2,3     # 3流派の学習の速さをくらべる
node tools/lab.mjs shiken --combo  # 模倣→強化の合わせ技
```

開発中は `?go=ga&stage=oni` で修行画面から、`?test=world&stage=toge` で 3D の確認画面から始められます（`?nosw` で Service Worker を無効化）。
